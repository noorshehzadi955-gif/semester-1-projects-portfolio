# Semester 1 Projects Portfolio

## Overview

This project is a portfolio-style landing page created to showcase my first-semester academic journey.

The website presents my semester projects, experiences, and learning outcomes through a clean and visually engaging web interface.

## Project Purpose

The purpose of this website is to bring my first-semester work together in one place and present my academic projects and experiences in an organized format.

## Features

- Responsive landing page design
- Hero section
- Semester project showcase
- Project links and resources
- Campus life section
- Semester reflection section
- Interactive project buttons
- Hover effects
- Modern card-based layout

## Projects Showcased

The landing page includes the following semester projects:

- ICT Presentation
- English Imaginary Creature Presentation
- Physics Metal Detector
- Leading with Character Video
- ICT Lab Compilation Project

## Technologies Used

- HTML5
- CSS3

## Website Sections

### Hero Section

Introduces the Semester 1 journey and purpose of the portfolio.

### Projects Section

Showcases the academic projects completed during the semester with links to their resources.

### Campus Life

Highlights activities and experiences beyond the classroom.

### Reflection

Summarizes the learning experience and personal growth throughout Semester 1.

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

No additional software or dependencies are required.
