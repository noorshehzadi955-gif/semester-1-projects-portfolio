# Semester 1 Projects Portfolio

## Overview

This project is a portfolio-style landing page created to document and showcase our first-semester academic journey.

The website presents our semester projects, team members, campus experiences, and key learning outcomes through a clean and responsive web interface.

## Project Purpose

The purpose of this website is to bring our first-semester work together in one place and present our academic projects and experiences in an organized and visually engaging format.

## Features

- Responsive landing page design
- Hero section introducing the team
- Team member profiles
- Semester project showcase
- Project links and resources
- Campus life section
- Semester reflection section
- Interactive project buttons
- Hover effects and modern card-based layout

## Projects Showcased

The landing page includes the following semester projects:

- ICT Presentation
- English Imaginary Creature Presentation
- Physics Metal Detector
- Leading with Character Video
- ICT Lab Compilation Project

## Technologies Used

- HTML5
- CSS3
